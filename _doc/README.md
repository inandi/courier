## Overview

Courier creates GitHub issues directly from VS Code using Markdown (.md) files. Each project can define its own template for parsing .md content.

## Usage

- **Epic:** High-level value statement (As a... I want... So that...)
- **User Story:** Granular, testable requirement with acceptance criteria
- **Checkboxes:** Track completion per acceptance criterion
